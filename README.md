# EGX AI Copilot | المستشار الذكي للبورصة المصرية 🇪🇬

تطبيق ويب سحابي متكامل وموحد لمتابعة وإدارة محفظة الأسهم في البورصة المصرية (EGX)، مبني للعمل مباشرة عبر **Vercel** ومربوط بـ **GitHub** بدون الحاجة لأي برامج محلية.

---

## الميزات الرئيسية
- **إدارة المحفظة الفعلية:** رصد الـ 10 أسهم القيادية وصندوق إن آي كابيتال (~200,000 ج.م) وحساب الأرباح والخسائر ونسب العوائد لحظياً.
- **رادار الطفرات والسوق:** مسح شامل لمؤشرات EGX30 و EGX70 لاكتشاف تدفقات السيولة غير المعتادة واختراق المقاومات.
- **مستشار مالي ذكي مدمج (In-App AI Copilot):** إجابات واستشارات فورية ومسببة وفق قواعد الاستثمار المعتمدة.
- **التكامل مع ثندر (Thndr):** زر تنفيذ سريع ومباشر لكل سهم لفتح صفحة التداول في ثندر بضغطة واحدة.
- **دستور وقواعد الاستثمار:** الامتثال الصارم لقواعد الاستثمار طويل الأجل الموثقة في `INVESTMENT_RULES.md` (حظر المضاربة اليومية، وعدم البيع إلا لحماية كبرى أو لاقتناص طفرة).

---

## النشر السحابي (Deployment)
المشروع جاهز ومعد للنشر المباشر على منصة **Vercel** بمجرد رفعه على مستودع **GitHub**.
